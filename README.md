# Global Central Bank & Academic Bibliometric Network

Standardized bibliometric network dataset mapping collaborative research ties and institutional linkages across global central banks, academic departments, and policy research institutes ($N=23$) Visualization Pipeline Pajek. Data harvested from the IDEAS/RePEc database.

## Structure follows
* `global_central_banks_network.net`: Directed edge list and collaboration weights.
* `institutional_colors.clu`: Categorical partition vector (1: Central Banks, 2: Universities, 3: Research Institutes).
* `institutional_sizes.clu`: Degree-centrality-based node sizing partition.
